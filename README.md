# Ultimate Tag

A simple, classic-looking Roblox tag game. The code lives in files here and syncs into Roblox Studio with [Rojo](https://rojo.space).

## First-time setup
1. Install [Rokit](https://github.com/rojo-rbx/rokit).
2. Double-click `scripts/setup.command`. It installs the tools and the Rojo Studio plugin, and builds `UltimateTag.rbxlx`.

## Every day
1. Double-click `scripts/start.command`. It opens VS Code and Studio and starts `rojo serve`.
2. In Studio, open **Plugins > Rojo**, set the port to **34872**, and click **Connect**.
3. Edit files in `src/` and they update live in Studio. Press Play to test.

See `AGENTS.md` for the project layout and conventions.
