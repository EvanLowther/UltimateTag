# UI style

Moved out of AGENTS.md. Read it before working on any file listed in `paths` above.

- **UI** (every menu, popup and HUD piece) uses the "Street sprint" style in `client/Menu/Ui.luau`: flat black panels with cut corners (`Ui.panel`), slanted bars, tabs and buttons (`Ui.slab`, `Ui.button`, `Ui.tabs`), hazard yellow, hot pink, cyan and lime, Bangers headlines (`Ui.title`) over heavy Titillium Web capitals (`Ui.caps`), slanted progress bars and XP segments, rarity strips (`Ui.rarityStrip`; Iridescent shimmers with `Ui.holo`), a coin pill and a column of slanted page buttons on the left, the level bar at the bottom center. Each window has its own header color (Shop yellow, Locker cyan, Quests pink, Rewards lime, Leaders orange). Build new UI from these helpers, not raw instances. (The dev panel keeps its own plain look.) **No emoji anywhere** (menus, HUD or world effects): icons come from `client/Icons` (`Ui.icon`, `Ui.centerIcon`, `Ui.iconText`, a button's `icon`; in BillboardGuis `Icons.draw`) and are uploaded images, drawn as SVG in `tools/icons` (since 0.65.0): objects in three-quarter view (a lit white front, a pale top, a grey side), ink outlines, a forward lean (skew -8), a hard offset shadow in the icon's colour and speed lines on the left (`objects.mjs`: pages, coins, marks, quests); each tag effect and victory has its own full picture in its item's colours (`effects.mjs`, `victories.mjs`; icons `tag<Effect>` and `victory<Victory>`). Every icon shares one spec in a 100 box: outline 3.4, shadow offset 3.8 x 3.2, small bits thinner; light (sparks, rings, bolts, fire) glows, solid things are outlined. A new or changed icon: draw it there, `node tools/icons/render.mjs` (PNGs via headless Chrome), then the owner runs `python3 tools/icons/upload.py build/icons` with their own API key (Assets read and write plus Legacy Assets, to look up each decal's image), which writes `shared/IconImages` (`Config.Icons.Images`). Images keep their own colours (`color`, `accent`, `Icons.paint` and `Icons.holo` only affect the fallback); an icon without an image falls back to the old code drawing (`DRAW` in `client/Icons`), so the game works before the upload. Text sizes go through `Ui.readable` (in `Ui.text`, so `Ui.caps`/`Ui.title`, and in `Ui.shrinkText`, `Ui.setTextSize`, `Ui.tabs`): anything under 24 is drawn bigger (11 becomes 16, 13 18, 16 20, 20 23) and nothing shrinks below `Config.Ui.MinTextSize` (15), so write the design size and give the box room for the raised one; never feed `Ui.readable`'s result back into those helpers. Gotchas: upper-case with `Ui.upper`, never `string.upper` (it mangles accented names in Roblox); a frame with AutomaticSize can't hold Scale-sized children such as a slab's pieces (they stretch it to fill its parent), so size it with `Ui.fitWidth`; keep an icon's frame square (the fallback's shapes are sized against both sides, so turned shapes skew in a wide frame); give fallback icons on the dark wells a light accent (a dark one vanishes).
